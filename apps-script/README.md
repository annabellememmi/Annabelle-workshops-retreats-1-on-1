# חיבור ההרשמות לגוגל שיטס (פעם אחת, כ־5 דקות)

כל מי שממלאת את הטופס בדף תופיע אוטומטית כשורה בגיליון, עם הסטטוס שלה:
**נרשמה – טרם שילמה** → **עברה לדף התשלום** → **דיווחה ששילמה – לאמת**.
אחרי שראית את הכסף בביט / פייבוקס — מסמנת ✔ בעמודה "שולם".

1. פתחי גיליון חדש ב־Google Sheets (למשל בשם "הרשמות לאירועים").
2. בתפריט: **תוספים (Extensions) ← Apps Script**.
3. מחקי את מה שכתוב שם, והדביקי את כל התוכן של הקובץ `Code.gs` שבתיקייה הזו. שמרי (💾).
4. למעלה בחרי את הפונקציה `setup` ולחצי **הפעלה (Run)**. אשרי את ההרשאות שגוגל מבקש (זה הסקריפט שלך, בחשבון שלך).
5. לחצי **פריסה (Deploy) ← פריסה חדשה (New deployment)**:
   - סוג: **אפליקציית אינטרנט (Web app)**
   - הפעלה בתור: **אני (Me)**
   - למי יש גישה: **כל אחד (Anyone)**
6. העתיקי את הקישור שמתקבל (מתחיל ב־`https://script.google.com/macros/s/...`) ושלחי לי אותו —
   או הדביקי אותו בעצמך בקובץ של האירוע, בשורה `sheetEndpoint: ""`.

> אם תשני את הקוד בעתיד: **Deploy ← Manage deployments ← ✏️ ← Version: New version** — כך הקישור נשאר אותו קישור.
